# Pulse Terminal ⚡

A custom developer command center and new tab page built for the Hack Club Stardance "Give Your Website a Pulse" mission. 

Designed to replace standard, boring browser tabs, this project acts as a live workspace. It features a fully functional Command Line Interface (CLI) search router, live system metrics, and a dark IDE-inspired aesthetic complete with CRT scanlines and a glowing pulse indicator.

**🚀 Check out the live site here:** [Pulse Terminal](https://kxrtik13-a19.github.io/Parallax-New-Tab/)

## 🚀 Core Features
* **CLI Search Engine:** A custom command-prompt router that lets you search directly across different developer platforms without leaving the tab.
* **Live System Pulse:** A dynamic status indicator that tracks network connectivity in real-time.
* **Dynamic Injector:** Automatically loads randomized software engineering tips on every refresh.
* **CRT Grid UI:** A pure CSS-generated blueprint background overlaid with deep glassmorphism blur filters and retro scanlines.

## 💻 CLI Routing Commands
Type these prefixes into the terminal prompt to instantly route your search to the right platform:
* `/gh [query]` -> Searches **GitHub** (e.g., `/gh react router`)
* `/so [query]` -> Searches **StackOverflow** 
* `/yt [query]` -> Searches **YouTube**
* `[query]` -> Defaults to a standard **Google** search

## 🛠️ Tech Stack
Built entirely from scratch to ensure maximum speed and zero bloat:
* **HTML5:** Semantic architecture
* **CSS3:** Custom variables, grid layouts, keyframe animations, and glassmorphism
* **ES6 JavaScript:** DOM manipulation, time/date logic, and search routing protocol (Zero frameworks or libraries used)

## ⚙️ How to Run Locally
Since this is a 100% vanilla build, no package managers (like npm) are required.
1. Clone the repository: `git clone https://github.com/Kxrtik13-A19/Parallax-New-Tab.git`
2. Open the project folder.
3. Open `index.html` in your browser.
4. *Optional:* Use a browser extension like "Custom New Tab" to set this local file as your default new tab page!
