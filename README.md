# pulse terminal ⚡

hey! i built this custom developer new tab page for the hack club stardance "give your website a pulse" mission. 

i was sick of boring default browser tabs, so i coded this live workspace to look like a dark-mode IDE or terminal. 

**Updates:**
* restyled script.js and style.css with my ideas and this time absolute 0% AI used.
* replaced old local host 3000 with Discord.
* added new command /yt for youtube searches.
* new colors and design.

**what it actually does:**
* it has a fully working command-line interface (CLI) router. if you type `/gh [query]` it actually searches github directly. `/so` searches stackoverflow, `/yt` for youtube, and standard text defaults to google.
* live system clock and a network status pulse indicator.
* crt scanlines and a css blueprint grid to make it look retro.
* zero dependencies. 100% pure vanilla html, css, and js.

**how to run it:**
just clone the repo and double-click `index.html` to open it in your browser.
