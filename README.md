# Pulse Terminal ⚡

A custom developer command center and new tab page built for the Hack Club Stardance Challenge. Designed to replace boring browser tabs, it acts as a live, dark-IDE workspace featuring a functional CLI search router, real-time system metrics, and injected dev tips.

**🚀 Live Node:** [Pulse Terminal](https://kxrtik13-a19.github.io/Parallax-New-Tab/)

## ⚙️ Build Specs
* **CLI Router:** Search GitHub (`/gh`), StackOverflow (`/so`), YouTube (`/yt`), or Google (default) directly from the custom terminal prompt.
* **Live System Pulse:** Tracks network connectivity with a dynamic status indicator.
* **CRT UI:** CSS-generated blueprint grid overlaid with glassmorphism and retro scanlines.
* **Tech Stack:** 100% Vanilla HTML, CSS, and ES6 JavaScript (Zero dependencies, zero bloat).

## 🚀 Quick Start
Since this is a pure vanilla build, no package managers are required. 
1. Clone the repository.
2. Open `index.html` directly in your browser.
3. *Optional:* Use a "Custom New Tab" browser extension to set this local file as your permanent workspace!
